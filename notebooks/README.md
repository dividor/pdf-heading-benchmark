# Notebooks

[Rebuild and test our CPU heading model](rebuild_heading_model.ipynb) runs the existing pipeline scripts in order: public download, checksum and annotation verification, training, validation selection, regression and prediction. It does not reimplement training in notebook cells.

Follow the [fresh-checkout instructions](../docs/rebuild-heading-model.md) for installation, **Run All**, headless execution and testing your own PDF. Full logs, models and raw outputs are stored outside the checkout. Keep only compact notebook output in Git.
