# Heading illustrations and result panels

These original explanatory diagrams use invented text. They are not WFP report quotations, model outputs or additional benchmark results.

- `heading-classification.svg` / `.png`: correct section, subsection and body-text labels compared with an incorrect hierarchy.
- `heading-relevance.svg` / `.png`: why a summary passage and an acronyms entry can have different relevance to a user's question.

The SVGs are editable source artwork. The PNGs are 1920 × 1040 exports for the README and article. Both are covered by this repository's MIT license. Text alternatives and captions accompany the embedded images.

Regenerate the PNGs from the SVGs using the project's existing PyMuPDF dependency, from the repository root:

```bash
uv run python - <<'PY'
from pathlib import Path
import pymupdf

for source in Path('docs/images').glob('heading-*.svg'):
    with pymupdf.open(source) as vector:
        pdf_bytes = vector.convert_to_pdf()
    with pymupdf.open(stream=pdf_bytes, filetype='pdf') as document:
        document[0].get_pixmap(matrix=pymupdf.Matrix(1.6, 1.6)).save(source.with_suffix('.png'))
PY
```

## On-premises result panels

`on-prem-quality.svg` / `.png` and `on-prem-timings.svg` / `.png` present all 25 local configurations, ranked by joint heading-and-level F0.5. Quality shows joint precision and joint recall, including correct-pair counts, false headings and missed titles. Timings state each run's measured scope. These are measured benchmark results, unlike the illustrative heading examples above. They contain no hosted-service rows or API price columns. The SVG files are editable; the PNGs are 1690 pixels wide.

Regenerate both panels with `uv run python scripts/report_panels.py`. The accessible HTML and Markdown tables are generated by `uv run pdf-headings report`.

## Published comparison

`published-comparison.svg` / `.png` are original charts of external scores reported by OpenBMB, not our WFP measurements. `configs/published-comparison.json` contains the transcribed values, pinned source table and date. `docs/published-comparison.md` supplies the accessible table and interpretation. Regenerate the diagram with `uv run python scripts/published_comparison.py`, then regenerate the report. The report copies the PNG into its output folder so it works on the local HTTP server. The local blog uses the same diagram.

## Supervised-method review images

`supervised-method.svg` is the editable pipeline diagram; `supervised-method.png` is its raster version. `supervised-annotation-overlay.png` shows frozen labels over an actual report-611 page. `supervised-toc-atlas.png` collates the source contents pages for visual context.
