    Review policy and provenance

    Standalone section titles are H1–H6. Body text, contents entries, running headers, table captions, box labels and inline bold lead-ins are excluded. Wrapped headings contain multiple line IDs. Pages outside the frozen 152-page sample have no training labels.

    Annotations were created by one assistant using images, text and surrounding document context. No independent human adjudication has been performed. A matching model prediction does not validate an annotation. Annotation edits here do not retrain the model or revise reported scores.
